# FORMA — каталог онлайн-курсов

Сайт на Node.js, Express и EJS. На сервере формируются страницы каталога, отдельного курса, информации о платформе, входа администратора и ошибок. Курсы хранятся в облачной MongoDB Atlas; поиск, фильтр и API работают с коллекцией `courses`.

## Структура

- `server.js` — настройка Express, EJS, маршруты сайта и API.
- `db.js` — подключение к MongoDB Atlas.
- `make-hash.js` — генерация bcrypt-хеша пароля администратора.
- `migrate-data.js` — однократный перенос курсов из локального `data.json` в MongoDB.
- `enrollments.json` — заявки на курсы.
- `feedback.json` — сообщения из формы обратной связи.
- `views/index.ejs` — список курсов и пустое состояние.
- `views/feedback.ejs` — форма обратной связи и ошибки валидации.
- `views/film.ejs` — подробная страница курса (`/film/:id`, имя оставлено по условию задания).
- `views/about.ejs` — информационная страница.
- `views/login.ejs` — форма входа администратора.
- `views/error.ejs` — страница внутренней ошибки сервера.
- `views/404.ejs` — страница ненайденного маршрута.
- `views/partials/head.ejs`, `header.ejs`, `footer.ejs`, `card.ejs` — повторно используемые блоки.
- `public/css/style.css`, `public/js/app.js` — стили и обработчик формы добавления.
- `public/img/`, `public/fonts/` — локальные изображения и шрифты.

## Запуск

1. Создайте бесплатный кластер MongoDB Atlas и пользователя базы данных. В настройках Network Access разрешите подключение с вашего IP-адреса.
2. Создайте локальный `.env` и укажите строку подключения Atlas:

```dotenv
MONGODB_URI=mongodb+srv://USERNAME:PASSWORD@CLUSTER_HOST/cinema?retryWrites=true&w=majority
```

Файл `.env` не добавляйте в Git. Курсы хранятся в облачной базе `cinema`, коллекции `courses`; `data.json` в репозитории отсутствует. Скрипт `npm run migrate` нужен только при наличии локального `data.json` для переноса.
3. Установите зависимости и запустите сайт:

```bash
npm install
npm start
```

Откройте `http://localhost:3000`. Если порт занят, в PowerShell задайте другой:

```powershell
$env:PORT = "3001"; npm start
```

### Вход администратора

Добавьте в локальный `.env` логин, bcrypt-хеш пароля и случайный секрет сессии. `.env` уже исключён из Git и не должен публиковаться.

В PowerShell создайте хеш, предварительно заменив пароль на свой:

```powershell
$env:ADMIN_PASSWORD = "ваш-надёжный-пароль"
node make-hash.js
Remove-Item Env:ADMIN_PASSWORD
```

Скопируйте выведенный хеш в `.env` и добавьте остальные параметры:

```dotenv
ADMIN_LOGIN=admin
ADMIN_HASH=$2b$10$вставьте_сюда_полный_хеш
SESSION_SECRET=вставьте_сюда_случайную_строку
```

Сгенерируйте `SESSION_SECRET` командой:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

Вход доступен по `/login`; незаметная ссылка на него находится в зелёном подвале и появляется при наведении или фокусе (на сенсорных экранах отображается). После авторизации администратор может добавлять, изменять и удалять курсы прямо из карточек каталога. Страница `/add` ведёт к форме добавления. API создания, изменения и удаления курсов защищено проверкой сессии; чтение каталога и запись на курсы остаются публичными. Сессия действует два часа, cookie имеет флаги `HttpOnly` и `SameSite=Lax`. Для постоянного развёртывания настройте хранилище сессий вместо стандартного временного хранилища Express.

## Страницы и проверка

| Запрос | Ожидаемый код | Получен при проверке | Результат |
| --- | ---: | ---: | --- |
| `GET /` | 200 | 200 | Список курсов, общий header/footer и карточки |
| `GET /film/1` | 200 | 200 | Подробная страница курса №1 |
| `GET /film/999` | 404 | 404 | Общая EJS-страница ошибки |
| `GET /about` | 200 | 200 | Страница о платформе с общими блоками |
| `GET /feedback` | 200 | 200 | Форма обратной связи |
| ` /feedback` | 303 | 303 | Валидация и сохранение обращения в `feedback.json` |
| `GET /login` | 200 | 200 | Форма входа администратора |
| `GET /add` без сессии | 302 | 302 | Перенаправление на `/login` |
| `GET /qwerty` | 404 | 404 | Та же EJS-страница ошибки |
| `GET /?q=not-a-course` | 200 | 200 | Сообщение «Записей пока нет» |
| `GET /css/style.css` | 200 | 200 | Файл стилей |
| `GET /js/app.js` | 200 | 200 | Клиентский JavaScript |

Пустое состояние списка отображается, если коллекция `courses` в MongoDB пуста.

## API

| Запрос | Получен при проверке | Результат |
| --- | ---: | --- |
| `GET /api/items` | 200 | Объект `{ total, page, limit, items }` с первой страницей (10 курсов) |
| `GET /api/items?category=Программирование` | 200 | Страница курсов выбранной категории |
| `GET /api/items?level=Начальный&page=2&limit=5` | 200 | Фильтрация и пагинация (максимум 50 элементов на странице) |
| `GET /api/items?q=python` | 200 | Поиск по названию, описанию и преподавателю |
| `GET /api/items/1` | 200 | Один курс |
| `GET /api/items/999` | 404 | JSON-ошибка |
| `POST /api/items` без сессии администратора | 401 | Запрос отклонён |
| `POST /api/items` с непустым `title` и сессией администратора | 201 | Новый курс (тестовая запись удалена) |
| `POST /api/items` без `title` | 400 | JSON с ошибкой валидации |
| `PUT /api/items/:id` без сессии администратора | 401 | Запрос отклонён |
| `PUT /api/items/:id` с сессией администратора | 200 | Курс обновлён |
| `DELETE /api/items/:id` без сессии администратора | 401 | Запрос отклонён |
| `DELETE /api/items/:id` с сессией администратора | 204 | Курс удалён |
| `POST /film/9/enroll` с корректными данными | 303 | Перенаправление на страницу курса с подтверждением (тестовая заявка удалена) |

Список API возвращает объект `{ "total": <число>, "page": 1, "limit": 10, "items": [...] }`. Доступны фильтры `category` (также `genre`), `level`, `q`, а также `page` и `limit` (не более 50 записей на страницу). Минимальный JSON для добавления или изменения записи: `{"title":"Курс по JavaScript"}`; остальные поля заполняются сервером значениями по умолчанию. Форма преподавателя отправляет расширенный объект.

Заявки и сообщения обратной связи по-прежнему сохраняются в `enrollments.json` и `feedback.json`. Не используйте реальные персональные данные в публично размещённой версии.
